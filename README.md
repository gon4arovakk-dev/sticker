Репозиторий Sticker Maker (Background Removal)
Описание
Sticker Maker – это набор консольных утилит на 8 языках программирования для удаления фона с изображений и создания стикеров с прозрачностью. Программа принимает входное изображение (PNG, JPG, WebP), определяет фон (по умолчанию – доминирующий цвет по краям) и удаляет его, сохраняя результат в формате PNG с альфа-каналом. Поддерживаются настройки: указание цвета фона вручную, порог чувствительности, выбор алгоритма (простой / улучшенный).

Возможности
Удаление фона на основе доминирующего цвета краёв изображения (простой алгоритм).

Ручной выбор цвета фона для удаления (HEX или название цвета).

Настройка порога (0–100) для определения схожести цветов.

Автоматическое определение – если не указан цвет, используется цвет, наиболее часто встречающийся по краям.

Поддержка форматов – на вход принимаются JPG, PNG, WebP; на выходе всегда PNG с прозрачностью.

Цветной вывод (в некоторых реализациях) с информацией о процессе.

Пакетная обработка – возможность обработать несколько файлов за раз (опционально, в некоторых версиях).

Использование
text
sticker [опции] <входной_файл> [выходной_файл]
Опции
Опция	Описание
-c, --color	Цвет фона в HEX (например, #FFFFFF) или название (white, black, ...).
-t, --threshold	Порог схожести цветов (0–100, по умолчанию 30).
-o, --output	Выходной файл (PNG). Если не указан, добавляется _sticker к имени.
-v, --verbose	Показать дополнительную информацию.
-h, --help	Показать справку.
Примеры
bash
# Автоопределение фона
python sticker.py input.jpg

# Указать цвет фона
python sticker.py input.jpg --color #00FF00

# Указать порог и выходной файл
python sticker.py input.jpg -t 50 -o output.png
Алгоритм работы (упрощённый)
Загрузка изображения.

Определение цвета фона:

Если цвет не задан вручную, анализируются пиксели по краям изображения (верхняя, нижняя, левая и правая строки). Вычисляется средний цвет (или наиболее частый).

Создание маски прозрачности:

Для каждого пикселя вычисляется цветовое расстояние до фонового цвета (в пространстве RGB).

Если расстояние меньше порога, пиксель становится полностью прозрачным (альфа = 0). Иначе сохраняется с альфа = 255.

Сохранение результата в PNG с альфа-каналом.

В более продвинутых реализациях (Python, JS) могут использоваться нейросетевые модели для более точного удаления фона.
